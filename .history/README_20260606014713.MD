# Wonderlust

A full-stack travel and accommodation booking web application inspired by Airbnb. Users can explore listings, view property details, create new listings, upload images, and manage travel stays.

## Features

- User Authentication & Authorization
- Create, Edit, and Delete Listings
- Image Upload Support
- Interactive Property Cards
- Responsive UI
- MongoDB Database Integration
- Session Management
- Flash Messages
- Server-side Validation

## Tech Stack

### Frontend
- HTML
- CSS
- Bootstrap
- EJS

### Backend
- Node.js
- Express.js

### Database
- MongoDB
- Mongoose

### Authentication
- Passport.js
- Express Session

## Installation

1. Clone the repository

```bash
git clone <repository-url>
```

2. Install dependencies

```bash
npm install
```

3. Configure environment variables

Create a `.env` file and add:

```env
ATLASDB_URL=your_mongodb_connection_string
SECRET=your_secret_key
```

4. Start the server

```bash
npm run dev
```

5. Open in browser

```text
http://localhost:8080
```
